# AGENTS.md

## This Repo

Static HTML landing page for Jobsy (AI-powered job search assistant). No build system, no tests, no npm.

## Structure

- `index.html` - Single-page landing site with inline CSS
- `manifest.json` - PWA manifest
- Image assets: `favicon.ico`, `favicon.png`, `promo*.png`, `i*.png`

## Development

Edit `index.html` directly. No build, no bundler. Open the file in a browser to preview.

## Production URL

https://jobsy-test-landing.vercel.app

## Git Workflow

After any changes:
1. Commit with a descriptive message
2. Push to remote

## Content Notes

- Page content is in Russian (HTML `lang="ru"`)
- UI elements (buttons, footer) mix Russian and English
- Links point to `/app` (separate application, not in this repo)
